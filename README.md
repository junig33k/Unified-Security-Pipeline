## 🇬🇧 English

### Overview
Automated DevSecOps pipeline integrating a modular architecture for security scanning and payload mutation workflows.

### Architecture Components
* **Dork Scanner**: Target analysis and data collection module.
* **Payload Mutator**: Vector generation and transformation engine.
* **Orchestrator**: Core execution pipeline.

### Security & Quality Controls (CI/CD)
* **Code Linting**: `flake8` (PEP 8 compliance).
* **SAST (Static Application Security Testing)**: `bandit` (vulnerability identification).

## 🇵🇹 Português

### Visão Geral
Pipeline DevSecOps automatizado integrando uma arquitetura modular para varredura de segurança e mutação de payloads.

### Componentes da Arquitetura
* **Dork Scanner**: Módulo de análise de alvos e coleta de dados.
* **Payload Mutator**: Motor de geração e transformação de vetores.
* **Orchestrator**: Pipeline principal de execução.

### Controles de Segurança e Qualidade (CI/CD)
* **Linting de Código**: `flake8` (conformidade PEP 8).
* **SAST (Testes Estáticos de Segurança)**: `bandit` (identificação de vulnerabilidades).
